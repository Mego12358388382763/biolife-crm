# Fibromyalgia & ME/CFS — research pack

Research for a BioLife recovery program. The full write-up (free PDFs, recovery books,
YouTube sources, existing programs compared, evidence grading, 12-week program design)
lives in the Claude doc:
https://claude.ai/code/artifact/7487d19d-8395-4a6d-b326-f42a8fbcb095

## Files

- `download-pdfs.sh` — fetches the free, officially published PDFs into `pdfs/`
  (run locally; the cloud session's network policy blocked these hosts).
- `recovery-stories-template.csv` — columns for logging recovery stories from YouTube
  interviews so recurring patterns can feed the program.

Only legally free documents are linked. Commercial books are listed for purchase,
not downloaded.
