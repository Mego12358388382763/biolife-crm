# SOP writer

## Interview (short)

What triggers the process, who does it, the steps as Ahmed does them today, tools used, what "done" looks like, common mistakes, and who to ask when stuck.

## Format

```
# SOP: <اسم العملية>
الهدف:
مسؤول: (الدور، مش الاسم)
إمتى: (الحدث اللي بيبدأ العملية)
الأدوات:
## الخطوات
1. ... (فعل واضح + فين في السيستم)
   ✔ علامة إنها اتعملت صح
## أخطاء شائعة
## أمثلة / نماذج رسائل
## مين أسأل
آخر تحديث: <date>
```

## Rules

- One action per step; name the exact CRM screen and button. Pipeline stages: use the ones configured in the CRM.
- Include time standards (e.g. "أي lead جديد يتكلم خلال 24 ساعة").
- Add ready-made messages from `whatsapp-followup` / `cold-email-writer` when relevant.
- Keep it one page when possible; link to sub-SOPs instead of growing it.
