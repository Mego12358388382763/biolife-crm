# Daily plan

1. **Collect**
   - Calendar today (`list_events`): fixed meetings.
   - CRM: follow-ups due/overdue and tasks due today (from an export or what the user shares).
   - Gmail: threads needing a reply today (quick `inbox-triage` pass).
   - Content: what's scheduled/needed today (`content-calendar`).
2. **Prioritize**: top 3 that move revenue or key goals. Hot leads' follow-ups outrank admin work.
3. **Time-block** around meetings: deep work block in the morning, calls block, WhatsApp/follow-up block, content block, buffer. Be realistic — leave 20% slack.
4. **Output** (short, Egyptian Arabic):
   ```
   أهم 3 حاجات النهارده:
   الجدول:
   09:00–10:30 ...
   فولو أب لازم يتعمل: (اسم — ليه — القناة)
   ممكن يتأجل:
   ```
5. Only create calendar blocks if the user asks.
