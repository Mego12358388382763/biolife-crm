# Sales deck

## Story (10–12 slides)

1. Title — tailored to the client ("BioLife × <Client>")
2. Their world — the problem/opportunity in their segment
3. Cost of doing nothing
4. What BioLife does (one sentence) 
5. How it works — 3 steps
6. Why it works — evidence (accurate, sourced; check with `health-claim-check`)
7. What it looks like for them — tailored scenario
8. Results / proof — real only
9. Offer & options
10. Implementation timeline
11. Next step — one clear ask
12. Contact

## Rules

- One message per slide, headline as a full sentence, minimal text; details go in speaker notes.
- Use the presentation artifact/slides type if available; otherwise the `pptx` skill when a .pptx file is requested.
- Arabic decks right-to-left. Keep brand colors/logo if provided.
- Ask for real numbers, prices and client names instead of placeholders that look real.
