# Newsletter writer

## Issue structure (400–700 words)

1. Subject line ×3 options + preview text (≤ 90 chars)
2. Opening: a short personal moment or client story (with consent, anonymized)
3. The idea of the week: one concept (gut–brain, stress & digestion, sleep, self-healing…) explained simply
4. Practical: 3 steps readers can do this week
5. Myth vs evidence (optional) — via `health-claim-check`
6. Soft CTA: reply with a word, book a call, join a program — one CTA only
7. P.S. — the line most people read; use it for the CTA or a personal note

## Rules

- Voice from `brand-voice`, Egyptian Arabic unless the list is English.
- Link to the latest content (from `repurpose-engine`).
- Include the unsubscribe placeholder; only send to people who opted in.
- If asked to put it in Gmail, create a draft, never send.
