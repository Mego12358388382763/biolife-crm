# Weekly KPI report

## Metrics

**Activity** (CRM daily activity/performance): calls, WhatsApp, meetings, proposals per person vs targets.
**Pipeline**: new leads (by source), moved forward, won/lost, pipeline value, overdue follow-ups.
**Marketing**: reach, engagement, leads from social/landing pages (Metricool + CRM `source`).
**Conversion**: lead → meeting → proposal → won.

## Steps

1. Gather: CRM export/Reports page numbers the user provides, Metricool data if connected. Ask for missing ones instead of estimating.
2. Compare to last week and to target: ▲▼ with %.
3. Write (Egyptian Arabic): 
   - الخلاصة في 3 سطور
   - الأرقام (table)
   - اللي ماشي كويس / اللي محتاج تدخل
   - أولويات الأسبوع الجاي (3)
4. Charts: at most 3, following `dataviz`.
5. Deliver as a shareable page/doc if it's for the team; offer to set it up as a recurring task every Sunday.
