# Objection playbook

## Method (for each objection)

1. **Acknowledge** — show you heard it, no arguing.
2. **Clarify** — one question to find the real objection ("غالي مقارنةً بإيه؟").
3. **Respond** — with value, proof, or an option (smaller package, pilot, payment plan) — only options the user confirms exist.
4. **Confirm & advance** — check it's resolved and propose the next step.

## Output per objection

- The likely real meaning behind it
- A spoken response (call) — 3–4 sentences, Egyptian Arabic
- A written response (WhatsApp/email)
- A question to ask back
- What not to say

## Common set to cover when building the playbook

غالي / مش وقته / هفكر وأرد عليك / ابعتلي على الواتساب / عندنا حد تاني / مش أنا اللي بقرر / مش مقتنع إنه بيفرق / مفيش ميزانية / جربنا حاجة زي كده قبل كده.

Evidence claims about health outcomes must pass `health-claim-check`. Save the playbook as a document if the user wants to share it with the team.
