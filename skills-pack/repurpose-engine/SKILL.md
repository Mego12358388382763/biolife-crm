# Repurpose engine

## Steps

1. Extract the core: the one big idea, 3–5 supporting points, best quotes, story moments, and the CTA.
2. Check claims once with `health-claim-check` before multiplying them everywhere.
3. Produce each format natively (not the same text pasted):

| Format | Shape |
|---|---|
| Reels ×3 | 20–40s, each one point, hook from `hook-factory` |
| Carousel | 7–9 slides: hook → points → recap → CTA (text per slide) |
| IG/FB caption | story opening, value, CTA, 5–8 relevant hashtags |
| LinkedIn | professional angle (for BD/corporates), English or Arabic, no hashtag spam |
| Newsletter section | 150–250 words + link |
| WhatsApp broadcast | 3–4 lines + one link |
| Stories ×5 | poll/question/quiz to drive replies |
| Quote cards ×3 | ≤ 15 words each |

4. Voice per `brand-voice`. Output grouped by platform, ready to copy. Offer to schedule via `content-calendar`.
