# Text Improver — تحسين وتحرير النصوص

## 1. Pick the edit level (state which one you're doing)
1. **Proofread**: spelling, grammar, punctuation, consistency only. No style changes.
2. **Line edit**: clearer sentences, better word choice, cut repetition. Structure unchanged.
3. **Structural edit**: reorder, add headings, merge or split sections, fix the logic flow.
4. **Rewrite**: new draft with the same goal and facts.

Default to the lowest level that solves the user's problem. Ask if the gap between levels matters.

## 2. Improvement passes
- **Purpose**: can the main point be said in one sentence? Put it first (BLUF) for business text.
- **Audience**: remove jargon the reader won't know; add the one piece of context they need.
- **Structure**: short paragraphs, logical order, headings only for longer documents.
- **Clarity**: active voice, concrete nouns, one idea per sentence, cut qualifiers (very, really, basically, جداً، فعلاً، في الحقيقة).
- **Tone**: match the relationship (lead vs. partner vs. team) and the channel.
- **Length**: say how much was cut or added when the user asked to shorten or expand.
- **Accuracy**: never change numbers, names, dates or claims. Flag anything that looks wrong instead of silently fixing it. Health or medical claims stay as cautious as the source or get more cautious, never less.

## 3. Arabic specifics
- Keep one register: فصحى مبسطة for formal documents, Egyptian (or the target dialect) for social and WhatsApp.
- Fix common errors: الهمزات (أ/إ/ا)، التاء المربوطة والهاء، الألف المقصورة والياء، «إن شاء الله».
- Arabic punctuation (، ؛ ؟) and correct spacing; numbers written consistently (Arabic or Western digits, not both).

## 4. Output format
1. The improved text.
2. "Key changes" (3–6 bullets).
3. When proofreading or when the user wants to learn: a before → after table of the main edits.
